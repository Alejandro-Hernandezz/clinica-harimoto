SOLUCION AL ERROR DE BASE DE DATOS

PASO 1: Ejecuta este comando
------------------------
setup-database.bat


PASO 2: Verifica que funciono
------------------------
verify-database.bat

Debes ver las 4 bases de datos:
- auth_service
- sensor_service
- analysis_service
- notification_service


PASO 3: Inicia los servicios
------------------------
start-all.bat


SI SIGUE SIN FUNCIONAR:
------------------------

Opcion A - Comando manual:

docker-compose down -v
docker-compose up -d postgres
timeout /t 20
docker-compose exec postgres psql -U riego_admin -d postgres -c "CREATE DATABASE auth_service;"
docker-compose exec postgres psql -U riego_admin -d postgres -c "CREATE DATABASE sensor_service;"
docker-compose exec postgres psql -U riego_admin -d postgres -c "CREATE DATABASE analysis_service;"
docker-compose exec postgres psql -U riego_admin -d postgres -c "CREATE DATABASE notification_service;"


Opcion B - Crear las bases de datos desde pgAdmin:

1. Abre http://localhost:5050
2. Login: admin@riego-smart.com / admin_password_2024
3. Conecta a servidor: localhost, usuario riego_admin, password riego_password_2024
4. Crea 4 bases de datos:
   - auth_service
   - sensor_service
   - analysis_service
   - notification_service
