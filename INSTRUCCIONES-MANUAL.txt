OPCION 2: DESDE LINEA DE COMANDOS
==========================================

Abre CMD (simbolo del sistema) y ejecuta estos comandos UNO POR UNO:

docker-compose exec postgres psql -U postgres -d postgres -c "CREATE DATABASE auth_service;"

docker-compose exec postgres psql -U postgres -d postgres -c "CREATE DATABASE sensor_service;"

docker-compose exec postgres psql -U postgres -d postgres -c "CREATE DATABASE analysis_service;"

docker-compose exec postgres psql -U postgres -d postgres -c "CREATE DATABASE notification_service;"


OPCION 3: QUERY TOOL EN pgAdmin
==========================================

1. Sigue los pasos 1-3 de la OPCION 1 para conectarte

2. Click en el servidor "RIEGO-SMART"

3. Click en "Databases" -> "postgres"

4. Click en el icono de rayo (Query Tool) o presiona Alt+Shift+Q

5. Copia y pega esto en el Query Tool:

CREATE DATABASE auth_service;
CREATE DATABASE sensor_service;
CREATE DATABASE analysis_service;
CREATE DATABASE notification_service;

6. Presiona F5 o click en el boton "Execute/Run"

7. Debes ver mensaje "Query returned successfully"

SI SIGUES TENIENDO ERRORES
==========================================

El error mas probable es que tu PostgreSQL use un usuario/password diferente.

Abre el archivo: backend/services/auth-service/src/app-simple.js

Busca la linea 14:
const sequelize = new Sequelize('auth_service', 'postgres', 'Adezito666', {

Cambia 'postgres' y 'Adezito666' por tu usuario y password real.

Repite lo mismo en:
- backend/services/sensor-service/src/app-simple.js (linea 14)
- backend/services/analysis-service/src/app-simple.js (linea 14)
- backend/services/notification-service/src/app-simple.js (linea 14)
